SOUNDBOARD V1.3 — MESA DE EFEITOS
Atualização visual de 24/10/2026

Interface profissional escura e dessaturada, com transporte compacto e 72 ícones
com contorno e segunda cor discreta. A biblioteca mantém 72 cadastros,
71 arquivos de áudio e a ação Silêncio dramático, com substituições feitas pelo usuário.

NAVEGAÇÃO
- Favoritos: seus efeitos de acesso imediato. Um toque reproduz; outro no mesmo
  cartão para somente aquele efeito. Outros cartões acrescentam sons à mistura.
- Vários efeitos e loops podem tocar ao mesmo tempo. Cada cartão mostra seu estado.
  PARAR interrompe todos os sons e cancela todos os carregamentos. Silêncio dramático
  também encerra a mistura. O volume e o compressor são gerais para todos os sons.
- Todos os efeitos: catálogo com pesquisa e categoria. No celular, são três colunas
  a partir de 360 px e duas em telas menores. Os cartões mantêm as dimensões ao tocar.
- Biblioteca: Adicionar som, Editar efeitos, reordenação dos favoritos, backups,
  importação, espaço local, instalação PWA, uso offline e créditos.
- Para editar: Biblioteca > Editar efeitos > cartão. Escolha um novo arquivo para
  substituir o áudio; o ID é preservado. Concluir edição volta à reprodução.
- O volume e Testar áudio ficam na barra compacta. A saída é escolhida pelo sistema.

CORES E ÍCONES
- 72 SVGs na grade 24x24 com contorno e detalhe em segunda cor discreta.
  28 bases Lucide, 7 Phosphor e 37 próprias/adaptadas. Licenças integrais locais:
  docs/licencas/ICONES-V13.txt e PHOSPHOR.txt. Matriz e folha: docs/ICONES-V13.md/PNG.
- O padrão oferece a paleta do sistema. Cores escolhidas pelo usuário continuam
  salvas. Tons pouco legíveis recebem ajuste apenas na exibição do ícone.
- SVG importado continua validado e exibido como imagem isolada, nunca como HTML.

PRESERVAÇÃO
- Os áudios atuais não foram recodificados. As substituições feitas pelo usuário
  aparecem no inventário com licença de uso declarada; as fontes das versões
  anteriores continuam registradas como histórico.
- Carregar arma usa sons/gun-load.mp3 e substitui Pancada. O arquivo sons/pancada.mp3
  foi removido. O ID interno continua builtin:pancada para manter favoritos/backups.
  Histórico de fontes/licenças preservado; inventário atual: audio-library.json.
  Detalhes e procedimento para novas trocas: docs/SUBSTITUICOES-AUDIO.md.
- IndexedDB, migração, backups com áudio, validações e gerência offline permanecem
  preservados. A reprodução agora mistura efeitos com volume e compressor gerais.
- Sons particulares continuam somente no navegador, sem publicação automática.
- sino-demo.wav já estava ausente antes da v1.2; nada foi fabricado com esse nome.

OFFLINE E ATUALIZAÇÃO
- Abra por HTTPS ou servidor local (não por file://).
- Biblioteca > Preparar uso offline: aguarde 71/71. Confira sem internet antes de usar.
- O cache da interface possui novo hash; o contêiner de mídia existente é reutilizado.
  Atualizar agora ativa a nova interface e recarrega sem apagar IndexedDB.
- Fechar todas as abas e reabrir também permite ativar uma versão aguardando.
  Não limpe dados do site para atualizar, pois isso remove seus arquivos particulares.
- Android: instalar pelo menu/botão disponível na Biblioteca. iPhone: Compartilhar >
  Adicionar à Tela de Início. Instalar não substitui a conferência dos áudios offline.

PUBLICAÇÃO
- Nenhum deploy foi realizado. O projeto é editado diretamente nesta pasta,
  sem geração de ZIP. Envie ao GitHub os arquivos do site indicados em
  docs/PUBLICACAO.md. A pasta work/ fica no computador e já consta na .gitignore.
- Prefira Git ou GitHub Desktop para preservar as pastas e ignorar work/.
  No navegador, envie até 100 arquivos por vez; assets/ exige duas remessas.
- GitHub Pages: Settings > Pages > Deploy from a branch > branch > /(root).
  Preserve os caminhos relativos e todos os créditos. Detalhes: docs/PUBLICACAO.md.
- Após trocar MP3 manualmente em sons/, mantendo os nomes, execute:
  python work/sync-audio.py
  python work/cache-v13.py
- Para alterações futuras de interface, execute python work/cache-v13.py; não é
  necessário instalar frameworks, runtime de ícones, CDN ou ferramenta de build.

VALIDAÇÃO E LIMITAÇÕES
- Testes Node, testes de interface/responsividade e fluxos Chrome completos foram
  executados. O inventário e cache correspondem aos áudios atuais. Armazenamento,
  backups, validações e módulo offline mantêm seus hashes originais.
- Não foi testado Safari/iOS físico, Chrome Android físico nem áudio em fones/Bluetooth.
  Emulação de tela/toque não equivale a teste em aparelho real.
- A escuta perceptual dos 71 áudios e a fluidez auditiva dos loops permanecem pendentes
  desde a curadoria v1.2; esta atualização não altera nem recertifica os sons.
- Bluetooth pode adicionar latência. O aplicativo não altera o volume físico.

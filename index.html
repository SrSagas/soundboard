    Ajuda para usar a Soundboard

    Um toque reproduz; outro toque no mesmo cartão interrompe. Outro cartão troca o efeito. PARAR também cancela carregamentos. A tecla Esc interrompe quando nenhum diálogo está aberto.

    Use Biblioteca → Editar efeitos para editar ou substituir um arquivo. Memes e TV está pronta para os arquivos que você tem autorização para utilizar; nada é enviado automaticamente.

    Bluetooth pode acrescentar latência. Para marcação extremamente precisa, prefira conexão por cabo. O aplicativo usa a saída escolhida pelo sistema e não altera o volume físico.

    O uso offline depende dos arquivos conferidos e da preservação dos dados locais pelo sistema. Exporte backups regularmente. Reabra o aplicativo após preparar o uso offline e teste antes de sair.

    No Android, use o menu do navegador para instalar. No Safari do iPhone, use Compartilhar → Adicionar à Tela de Início.

    O sino-demo.wav não estava na pasta original. Um sino real separado integra a curadoria; nenhum arquivo foi criado com o nome do ausente.
